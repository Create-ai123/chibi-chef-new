# Recipe pictures

You can add your own food pictures in this folder later.

For example:

- `banana-oat-pancakes.jpg`
- `cheesy-egg-toast.jpg`
- `speedy-egg-fried-rice.jpg`

Then set the recipe's `image` field in `src/lib/chef-steel-recipes.ts` to a path such as:

`/recipes/banana-oat-pancakes.jpg`

The app currently uses a cute food emoji when a recipe does not have a picture yet, so missing photos will not break the site.
